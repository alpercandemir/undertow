# Undertow product scope

The product executes reviewed business expectations in CI and gives engineers evidence to decide on a change.

## Active

- Bounded Java behavior search, reduction, exact-snapshot replay and standalone JUnit proposals.
- GitHub Actions candidate review, a decision summary, evidence artifacts and the eight-case gallery.
- Existing-suite comparison and authored fail-before/pass-after regression validation.
- Approved contracts, trusted CI import and explicit satisfied/unsatisfied/incomplete results.
- Structured contract reads, read-only MCP, local preview/freshness, SARIF and approved regression evidence.

## Retired

Hosted services/dashboard, browser playground, generic AI review/publication, release gates, artifact attestation, rollout operations and associated legacy demos are archived outside active code. See [the archive](archive/README.md).

## Next evidence

Integrate an independently selected compatible component, review its expectation and adapter, and collect decisions on real PRs. Record whether the reproduction adds information or a regression is actually retained. Keep authored demonstrations separate from independent accuracy and human time-saving claims.

The engineer reviews results. Implementation agents handle integration and accepted changes. Automatic source repair, test commits and merge are outside the current implementation.
