# Historical PR benchmark

**November 20, 2026.** Deterministic Undertow found none of the 18 labeled behavior changes in the historical corpus and added no findings beyond GitHub Copilot CLI. Copilot surfaced 15 of the 18, plus seven distinct source-supported outcomes outside the frozen labels. Undertow's zero findings make precision and example accuracy undefined.

## Dataset and comparison

- The frozen corpus contains 20 merged public Python library PRs, 10 each from Pallets Click and Encode HTTPX. It contains seven intentional changes to public behavior, nine fixes for reported bugs, and four runtime controls covering an annotation change, docs, tests, and a code-moving private-helper refactor. It includes library policy decisions such as query replacement, allowed proxy schemes, and JSON serialization. The 18 outcomes are retrospective source and test labels. They have no independent second adjudication or paired runtime replay. The selection favors cases with clear upstream evidence and has little coverage of Undertow's numeric rules or application-specific policies. [Frozen case metadata, outcomes, and evidence](historical.json) · [Baseline methodology](README.md)
- Click #2934 supplies a separately scored regression-introducing case. Its prompt EOF change also broke ordinary stdin iteration through `CliRunner`, as reported in #2939 and confirmed by the subsequent fix. The case and regression label were recorded before running either reviewer on it. The original manifest and `supported` flags remained unchanged. All 21 pinned heads were verified against GitHub's merged-PR metadata and their bases against the first Git parent. [Supplemental manifest](click-stdin-regression.json) · [Regression report](https://github.com/pallets/click/issues/2939) · [Upstream fix](https://github.com/pallets/click/pull/2940)
- Both tools received the same pinned base/head source and tests with their normal context selection. Copilot CLI `1.0.114` used a fixed source-review prompt and on-demand access to the exported trees and full diff. Undertow chose bounded source regions and references. Both ran without original PR discussions, later commits, or repository test execution. This evaluates the prompted CLI workflow. Its account default served `mai-code-2-flash` in 11 corpus runs and `gpt-6-luna` in nine. The supplement also used Luna. Explicitly selecting `mai-code-2-flash` failed before review. One run per case with mixed model routing limits repeatability, and public code may be familiar from model training. [Reproduction protocol](competitive-pilot.md)

## Strengths and gaps

- **Controlled coverage.** The local rules report named thresholds, multiline comparisons, and caller bindings on controlled Git fixtures. The release baseline, its rerun, and the worker with threshold and caller tracing all produced zero findings on the historical corpus. [Controlled checks](../tests/test_review_engine.py) · [Release baseline](baselines/v0.3.0-local.json) · [Release rerun](results/historical-release-rerun.json) · [Threshold and caller run](baselines/thresholds-and-callers-local.json)
- **Detection gaps.** The local rules missed public behavior caused by helper dispatch, serializer arguments, state and exception propagation, and import timing. Examples include Click's cleanup callbacks on context exit, HTTPX's rejection of non-finite JSON, and the supplemental stdin regression. Both tools missed Click's intended removal of the suffix from names such as `init_data_command`, the final empty string from HTTPX text streaming, and deferred loading of both HTTPX dependencies at package import. Copilot detected a related initial empty-chunk change and other observable import-PR effects. Those findings did not establish the frozen outcomes. [Click #2604](https://github.com/pallets/click/pull/2604) · [HTTPX #2998](https://github.com/encode/httpx/pull/2998) · [HTTPX #3377](https://github.com/encode/httpx/pull/3377)
- **False positives and witness errors.** Undertow produced no false positives on the corpus, with zero findings to assess. Copilot invented an empty generated name by overlooking the separator check in #2604 and claimed a chained completion difference contradicted by the unchanged test in #2935. Its other two false positives concern static typing on the annotation control. The live run also shows why witness accuracy merits its own metric. Copilot found the standalone timeout change but used relative URLs in its examples, which cannot reach the slow endpoint through the default HTTP transport. [Copilot adjudications](results/historical-copilot-adjudications.json) · [Click #2935](https://github.com/pallets/click/pull/2935) · [HTTPX #3116](https://github.com/encode/httpx/pull/3116)

The measured comparison covers two Python libraries and two source-review configurations. Gemini was unavailable for the recorded run. No independent maintainer assessments or changes to tests, fixes, or releases attributable to these reviews were recorded.
