## What the regression replay established

The base test used two substitution rules with a cycle. Undertow added leading spaces to both replacement strings, which preserved the cycle while changing the full replacement strings. The base threw `IllegalStateException`. The candidate returned a partially substituted string even though both search terms remained. The same generated JUnit test passed in three fresh base builds, failed at its assertion in three fresh candidate builds, and passed in a separate build of the upstream correction. The reproduced result agrees with the independently reported failure in circular replacements. The automatic report calls this an observed difference because the original test does not assert the exact generated inputs. [Base test](https://github.com/apache/commons-lang/blob/995dba307c9dd9e27dd602c3e1d5250c7d556643/src/test/java/org/apache/commons/lang3/StringUtilsTest.java#L1908) · [Upstream regression report](https://issues.apache.org/jira/browse/LANG-1753).

The run also found that the PR made a short repeated replacement succeed, the PR's intended improvement. A longer replacement produced a partial result on the candidate, while the pre-PR revision threw. That longer example needs the corrected behavior as its oracle. A replay of the older exception would preserve the wrong result there. [Introducing PR](https://github.com/apache/commons-lang/pull/505) · [Corrective PR](https://github.com/apache/commons-lang/pull/1297).

## Scope, effort and remaining checkpoints

- Initial runs exposed two setup obstacles. Historical Maven dependencies needed registry access. Apache RAT rejected generated sources until the tool learned to preserve the originating test's license header. The final runs used the same strategy on both repositories. No application code, POM, test fixture or selection hint was edited to rescue a pair. The separate correction check copied the validated export into a disposable checkout.
- The historical replay adds evidence beyond the selected existing tests, which passed on both revisions. Static review can point to the altered recursive termination path. The tested scenarios establish the exact returned values and exceptions. Human review time, understanding and test maintenance were unmeasured.
- The measured wall times include complete Maven invocations and three fresh replays per finding. The local replay runs overlapped, and dependency caches varied. Budget CI latency after isolated cold and warm runs. Model calls and model cost were zero.
- The first increment demonstrates repository-only discovery and paired replay. Two repositories consumed the same local runner. Structured fixture replay remains the main engineering gap before claiming broader Java/Maven support. The next estimate should cover fixture extraction, callback tracing and one held-out evaluation cycle, with CI latency measured separately.
- The Actions example and compatibility guide prepare a pilot. A published version, live verification from both repositories, a held-out case set and independent reviewer assessment remain pending. Adoption requires at least two weeks of normal PR use and ten distinct candidate revisions per repository, with owner decisions and human effort recorded.
