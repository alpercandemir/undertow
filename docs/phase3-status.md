P1 BYOK, machine tokens/remote client and payments, plus deferred providers/languages/enterprise hosting, remain excluded.

The regression suite exercises duplicate/reordered requests, 100 durable duplicate deliveries, concurrent overspend prevention, multi-tenant membership/source authorization, grant expiry after reservation, manual idempotency conflicts, pre/post-inference crashes, lease fencing, partial settlement, publication-only recovery, package ownership, model-authority separation, kill switch/removal/deletion, artifact expiry, encrypted restart, HMAC-before-parse and deterministic hosted/local equivalence. These are controlled internal tests with authored data and a fake GitHub gateway. They cannot certify the real GitHub App, container isolation, model quality, or pilot operating targets.

Local verification on October 6, 2026 passed 94 harness tests (including 22 service tests), formatting and SpotBugs with zero findings, 15 Python helper tests, and two customer-application tests. The packaged JAR's authored worker replay produced one finding with `status: partial`, `executionMode: replay`, and `billable: false`; it reports missing CI and unresolved analysis rather than a complete live review. The timeout test also verifies that a provider ignoring cancellation cannot block accounting or turn unknown usage into verified zero usage. Shell and browser JavaScript syntax checks passed. The existing Docker-dependent order/payment integration demo was not rerun.

Use `mvn verify`, `python3 -m unittest discover -s scripts/tests -v`, the customer-only application's `mvn verify`, and `scripts/phase3-demo.py` for reproducible local checks. The implementation deliberately reports `/health.externalPilotReady = false`. Advance that readiness claim only after the remaining implementation work and PRD gates are supported by actual evidence.
